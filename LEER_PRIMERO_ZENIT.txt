1. Compará tu HEAD y guardá tus cambios locales antes de extraer.
2. Aplicá la migración y prepará el acceso de la dueña con el ZIP backend.
3. En Vercel configurá ZENIT_API_URL con la URL HTTPS del backend actual, sin /api.
   La URL no se adivina: copiá la misma base real que ya usa NEXT_PUBLIC_API_URL.
   La variable antigua sirve como respaldo; se recomienda ZENIT_API_URL.
4. Desde la raíz del frontend:
   npm ci
   npm run lint
   npx tsc --noEmit
   npm run build
5. Revisá el diff y subí los cambios con los comandos habituales.
   git status
   git diff --check
   git add .
   git commit -m "Agrega agenda privada y acceso personal para Zenit Salon"
   git push origin main
6. Comprobá ZENIT_API_URL también en Production; cambiarla exige un redeploy.

  se revisan contra el catálogo al cargar y otra vez en servidor al confirmar.
- Sesiones HttpOnly, SameSite, Secure en producción; sin tokens en localStorage.
- El frontend debe ejecutarse con Next en Vercel/Node; la API intermediaria nueva
  NO funciona como exportación HTML estática.
- El POS y cuentas por cobrar siguen pendientes del trabajo en System Lab.
